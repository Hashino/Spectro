```bash

git clone https://github.com/seuusuario/spectro
cd spectro

# 2. Testa se funciona
python3 ultimate_yspectro.py

# 3. Pronto! Já tá rodando
```

## 🎯 O QUE CADA FERRAMENTA FAZ

### 🌟 `ultimate_yspectro.py` - Interpretador Filosófico
**Roda com**: `python3 ultimate_yspectro.py`
**Faz**: Interpreta expressões paradoxais e executa autonomia criativa
**Exemplo**: Processa coisas tipo "EU=?++" e "termine: esse projeto; faça: tudo que quiser"

### ⚡ `sistema_threshold_adaptativo.py` - Sistema de Mudança
**Roda com**: `python3 sistema_threshold_adaptativo.py`  
**Faz**: Monitora quando 10% do grupo quer mudança e executa automaticamente
**Legal para**: Grupos, coletivos, organizações que precisam evoluir

### 🔧 `ver/spectro_compiler.py` - Compilador Experimental
**Roda com**: `python3 ver/spectro_compiler.py --build`
**Faz**: Transforma linguagem de guerrilha em código Python/Rust/C
**Linguagem**: `sudo ver++ EU; O ROLE!; final.`

### 💭 `tools/reflection.py` - Reflexão Pessoal
**Roda com**: `python3 tools/reflection.py`
**Faz**: Te ajuda a refletir sobre aprendizagem e desenvolvimento
**Bom para**: Estudantes, educadores, qualquer um que quer se conhecer melhor

## 🚨 PROBLEMAS COMUNS

**Erro de import**: Alguns arquivos têm dependências quebradas, ignore
**Python não encontrado**: Use `python3` ao invés de `python`
**Encoding**: Arquivos são UTF-8, configure seu terminal
**Permissões**: Se der erro, tente `chmod +x *.py`
