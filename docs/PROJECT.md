# Sobre o Projeto

## O que é o Spectro

Spectro é uma metodologia educacional nascida das experiências vividas de comunidades marginalizadas no Sudeste brasileiro. Defende um processo criativo cíclico e sem limites, enraizado na compaixão, compreensão e vínculos humanos autênticos.

## Autor

Projeto desenvolvido a partir de experiências pessoais em comunidades periféricas. Ver [AUTHOR.md](AUTHOR.md) para contexto completo.

## Como Acessar

- **GitHub**: https://github.com/Hashino/Spectro
- **Clone**: `git clone https://github.com/Hashino/Spectro.git`

### Instalação Rápida
```bash
git clone https://github.com/Hashino/Spectro.git
cd Spectro
python3 tools/reflection.py
```

## Como Contribuir

1. Faça um fork do repositório
2. Clone seu fork localmente
3. Crie uma nova branch para suas alterações
4. Contribute com documentação, metodologia ou ferramentas

### Diretrizes
- Contribuições devem se alinhar com os princípios centrais
- Respeitar a abordagem educacional anti-manicomial
- Manter foco em comunidades periféricas e justiça social

## Descoobrimento

Pessoas encontrarão o projeto através de:
- "educação anti-institucional brasil"
- "metodologia partnership favela"
- "revolução educacional periférica"
- "pedagogia crítica"
